# MV連携 パーツ分離PSD出力ワークフロー — 進捗記録

> **最終更新:** 2026-06-12  
> **担当:** taketenkeishi-gif  
> **リポジトリ:** https://github.com/taketenkeishi-gif/painting-app

---

## 目的

1枚のイラスト画像を、静止画MV制作ソフトで動かせる**パーツ分離PSDファイル**として変換する。

各パーツ（前髪・頭・顔・目・手・体・首など）をレイヤーとして分離し、  
パーツをずらしたときに裏が空白にならないよう**カモフラージュ生成塗りつぶし**を施した状態でPSD出力する。

---

## ユーザーフロー（8ステップ）

```
[1] 画像インポート
      ↓
[2] 背景 / キャラクター分離（AI Roto Brush）
      ↓
[3] AI アップスケール（ComfyUI / ONNX）
      ↓
[4] エッジ強調（アンシャープマスク）
      ↓
[5] キャラクターパーツ レイヤー分離（SAM2 + 手動確認）
      ↓
[6] 各パーツの裏面 カモフラージュ生成塗りつぶし（AI インペイント）
      ↓
[7] レイヤー確認・手動調整
      ↓
[8] PSD 出力
```

## ステップ 3 — AI アップスケール ✅ 実装完了（今セッション）

**概要:** イラストの解像度を AI で高品質に拡大。ComfyUI のアップスケールモデルを直接使用するか、ローカルの ONNX モデルを使うか、バイリニア補間のフォールバックを使う3段構え。

### 実装ファイル

| ファイル | 役割 |
|----------|------|
| `src/core/ai/UpscaleEngine.h/cpp` | ONNX 推論エンジン本体（PIMPL、タイル推論）+ バイリニア補間フォールバック |
| `src/app/panels/UpscaleDialog.h/cpp` | アップスケール UI。ComfyUI / ONNX / バイリニアを自動切替 |
| `src/app/panels/AiModelFolderDialog.h/cpp` | AI モデル検索フォルダ管理ダイアログ（QSettings に永続保存） |
| `src/app/bridge/ComfyUiClient.h/cpp` | `fetchUpscaleModels()` + `buildUpscaleWorkflow()` 追加 |

### バックエンド優先順

```
ComfyUI 接続中 & ComfyUI モデル選択
    → ComfyUI の ImageUpscaleWithModel ノードで推論
    → safetensors / pth モデルをそのまま使用可能

ローカル ONNX モデルあり
    → ONNX Runtime でタイル推論（kTile=128, kPad=8）
    → .onnx ファイルを models/ フォルダに配置するだけ

何もなし
    → バイリニア補間（品質は低いが即動作）
```

## ステップ 5 — キャラクターパーツ レイヤー分離

**概要:** SAM2 でパーツ（前髪・顔・目・手など）ひとつひとつを選択し、選択範囲を独立レイヤーとして切り出す半自動フロー。

パーツ例: `前髪 / 後ろ髪 / 頭 / 顔 / 目_左 / 目_右 / 眉 / 口 / 耳 / 首 / 体 / 腕_左 / 腕_右 / 手_左 / 手_右`

| ID | タスク | 詳細 | 状態 | 優先度 |
|----|--------|------|------|--------|
| W-040 | SAM2 によるパーツ単位クリック選択 → マスク生成 | W-010 の Roto Brush をパーツ切り出しにも流用。繰り返し使用できるフロー | 🚫 W-010 別チャットで開発中 | High |
| W-041 | 「選択範囲を新規レイヤーとして切り出し」コマンド | 選択マスク範囲のピクセルをコピー → 新規レイヤー生成。`AppController::extractSelectionToNewLayer()` を追加 | ❌ 未実装 | High |
| W-042 | 切り出し後、元レイヤーの対応ピクセルを透明化 | 切り出しと同時に元レイヤーのマスク領域を透明にする。Undo/Redo 対応必須 | ❌ 未実装 | High |
| W-043 | パーツを自動命名してレイヤーグループに整理 | 「前髪」「顔」などのプリセット名でレイヤー名を設定。フォルダレイヤーに自動格納 | ❌ 未実装 | Medium |
| W-044 | パーツ定義テンプレート UI | 標準的なパーツ定義（前髪/頭/顔/目/手/体/首）を一覧表示し、順番に切り出せるワークフローパネル | ❌ 未実装 | Medium |
| W-045 | 切り出し済みパーツのマスク境界を数px拡張（隙間防止マージン） | 境界を 2〜4px 膨張させることでパーツ間の隙間を防ぐ。形態学的膨張（Morphological Dilation）で実装 | ❌ 未実装 | Medium |

**技術メモ:**
- W-041/042 は `SelectionMask` + `Layer::copyRegion()` + `Layer::clearRegion()` で実装可能
- W-045 は `cv::dilate()` 相当を自前実装か OpenCV を組み込む

## ステップ 6 — カモフラージュ生成塗りつぶし（AI インペイント）

**概要:** 各パーツを動かしたとき、パーツの裏側が空白（透明）にならないよう、周辺ピクセルから背景を AI 補完する。  
例: 「前髪」を上に動かしても、その下に元の画像の続きが見える状態にする。

| ID | タスク | 詳細 | 状態 | 優先度 |
|----|--------|------|------|--------|
| W-050 | LaMa インペイントエンジン実装 | `src/core/ai/InpaintEngine.h/cpp` を新規追加。LaMa（Large Mask inpainting）ONNX モデルを使用。ComfyUI 経由でも可 | ❌ 未実装 | High |
| W-051 | 選択マスクを受け取り → 塗りつぶし結果を下レイヤーに合成 | 処理フロー: `元画像 + パーツマスク → InpaintEngine → 補完ピクセル → 背景レイヤーに書き込み` | ❌ 未実装 | High |
| W-052 | 「全パーツ一括カモフラージュ生成」バッチ処理 | 全パーツレイヤーを順番に処理し、1クリックで全部のカモフラージュを生成する | ❌ 未実装 | Medium |
| W-053 | インペイント結果の手動修正ブラシ連携 | AI 補完が不完全な箇所を既存ブラシツールで手修正するだけ。UI 追加不要 | ✅ ブラシは既存実装 | — |

**技術メモ:**
- モデル候補: `lama_fp16.onnx`（Apache 2.0）。ONNX エクスポート版公開済み
- ComfyUI 経由なら `InpaintModelConditioning` + `KSampler` で同等の結果が出せる
- RTX 3060 で 1024×1024 を数秒以内で処理可能
