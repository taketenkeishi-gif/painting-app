# Roadmap

## Phase 1 (現状)

- 空プロジェクトのビルド成立
- コア最小実装（Document / Layer / PixelBuffer）
- レイヤー合成（標準アルファ）
- Qt 表示接続
- 丸ブラシの最小描画
- レイヤーパネル最小機能

## Phase 2

- Undo / Redo 基盤
- レイヤー削除
- レイヤー並び替え
- レイヤー不透明度UI

## Phase 3

- 消しゴム
- ズーム / パン
- ペンタブ入力

## Phase 4+

- 描画エンジンの高度化（Skia / libmypaint 検討）
- 保存形式の拡張
- UI 全面再設計
