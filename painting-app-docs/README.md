## 🚀 使用方法（推奨読順）

### ChatGPT に提供する場合

**ステップ 1:** プロジェクト全体を理解する
```
1. PROJECT_STATUS.md を読む（進捗確認）
2. SPEC.md を読む（ビジョン理解）
3. SPEC2.md を読む（実装仕様確認）
```

**ステップ 2:** 技術判断背景を理解する
```
4. DECISIONS.md を読む
5. adr/ フォルダから必要な ADR を読む
```

**ステップ 3:** 質問・依頼を実施
```
ChatGPT に「以下のドキュメントを読んで、[質問内容] に答えてください」と提示
```

### よくある質問シナリオ

#### A. 「次に実装すべきタスクは？」
→ PROJECT_STATUS.md の「次のタスク（優先順）」を確認

#### B. 「アーキテクチャはどうなっているか？」
→ SPEC2.md + architecture.md を読む

#### C. 「なぜ Skia を採用したか？」
→ adr/ADR-001-skia-backend.md を読む

#### D. 「ベクターレイヤーの実装方式は？」
→ DECISIONS.md の ADR-003 リンク + adr/ から確認

#### E. 「新機能実装の設計を手伝ってほしい」
→ PROJECT_STATUS.md で優先度確認 + SPEC2.md でデータモデル確認
